按关键词在搜索引擎里搜视频

先选视频源再搜索：只想在 YouTube 上搜，就把来源选成 YouTube（B 站同理）。 「全网」会一次查多个来源并合并去重，某个来源返回的内容与关键词无关时会自动丢弃并如实说明。
「国内主流 / 国外主流」= 多来源结果里的该地区站点 + 该地区主力站的定向检索 + 该地区有官方搜索接口的站点（国内并 B 站、国外并 YouTube 与 Dailymotion）。
「单站 · 按站点检索」会主动针对该站点检索——用检索语法限定域名， 并把站点名拼进关键词（如「科比 抖音」），两条手段并施后再按域名核准。 该站内容少时会如实告诉你找到几条。 极少数站点（优酷 / 快手 / 小红书 / Vimeo / X / Facebook）的视频只在自家 App 内， 公开网页里检索不到，选中时会直接说明原因。
成人向关键词（如「angela white anal」）会自动优先返回成人站点的结果 （Pornhub / Eporner）——通用搜索引擎对这类内容只给 YouTube 的采访花絮， 拿不到成人站的内容，所以这里单独去成人站检索。
兜底不限于上面罗列的站点：某个源结果不够时，会自动从全网补充， 并如实标注哪些是兜底来的。 搜到后可逐条「解析」确认，也可勾选多条批量下载。

下载设置

下载记录与去重

下载成功后会按视频身份记一笔（页面地址归一后的身份，或 yt-dlp 的 「来源站 + 视频 ID」）。它与文件放在哪儿无关：把已下载的视频移到别的目录、 甚至删掉，仍然算「下过」，下次搜同一个关键词不会再出现。 想再看到它们，把搜索结果筛选里的「隐藏已下载的视频」取消勾选即可。
注意：这与上面的「跳过已下载的相同文件」是两回事 —— 那条判断的是 下载目录里的文件还在不在（文件被移走就会重新下载）。

使用说明与合规提醒

能做什么：输入列表页/网站链接批量抓出图片、视频与流媒体（可整站遍历）； 按关键词搜图、搜视频并下载；输入视频页面链接解析清晰度后下载（支持上千个视频站点）。

关于清晰度筛选：搜索接口本身不提供可靠的原图像素尺寸，工具会逐个探测原图文件头 以取得真实分辨率，因此筛选越严格、耗时越长，这是准确性的必要代价。

关于部分站点抓不到：有些站点用 Cloudflare / Anubis 等人机验证，或依赖 JS 动态渲染， 静态抓取会被拦截，工具会明确提示原因，而不是静默返回空结果。 需要登录的已支持平台请在「平台登录」页建立独立登录态。

合规：本工具仅供个人学习与备份用途。请勿用于侵犯版权、绕过付费墙或大规模抓取。 下载的内容版权归原作者与站点所有，请遵守目标站点服务条款与当地法律。

首次使用与跨电脑说明

最简单的使用顺序：先直接粘贴公开链接尝试抓取；能用就不登录。只有遇到登录墙、403/412/429、 Bot Check、结果明显不完整，或主页/账号批量抓取为空时，再为对应平台建立登录态。

换电脑不会自动带走登录态：安装包不包含你的 Cookies、账号、浏览器 Profile、下载记录或私人配置。 每台电脑需要按实际需要重新登录。程序自己的 ffmpeg、yt-dlp、gallery-dl、JS 运行时已随安装包提供。

2.0 自包含：主页/列表能力由程序内置的 yt-dlp、gallery-dl、xhshow 与登录浏览器共同完成， 不再需要另外安装任何外部爬虫项目、Python 项目或配置外部项目路径。

遇到问题先这样判断

403 / 412 / 登录墙：通常是站点要求登录或当前 Cookie 失效。先到「平台登录」重新登录对应平台。

429：通常是访问频率或 IP 风控。降低频率、稍后重试；登录态有效也不代表一定不会被限流。

Sign in to confirm you're not a bot / Bot Check：多半是网络/IP/站点风控，不等于安装失败。换正常网络后再试。

批量能抓但数量明显少：先确认对应平台登录态是否有效；不同账号、IP、地区看到的内容也可能不同。

缩略图空白但视频能解析：通常是图床防盗链或登录态问题；Instagram 已有登录态/代理兜底，仍异常时先刷新登录态。

程序打不开：桌面壳默认使用 Windows WebView2；若桌面壳初始化失败，会回退到默认浏览器。 也可用 MediaDownloader.exe --browser 强制浏览器模式排错。

数据与隐私

账号 Cookies/Profile 保存在本机用户目录，不写进安装目录，也不会进入安装包。不要把 Cookie 文件发给别人。

默认下载目录：%USERPROFILE%\Downloads\MediaDownloader；程序配置/日志/登录态位于 %LOCALAPPDATA%\MediaDownloader。卸载程序默认保留这些用户数据和已下载文件。

其它电脑安装时出现 Unknown Publisher 是因为当前安装包尚未做商业代码签名；这与程序是否能运行是两回事。
